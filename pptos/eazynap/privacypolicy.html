プライバシーポリシー

株式会社コトシステム（以下「当社」）は、睡眠サポートアプリ「eazynap」（以下「本サービス」）における利用者の情報を、次のとおり取り扱います。

1. 端末内に保存する情報
声・環境音・音量・話し方・タイマーなどの設定、シーンとお気に入り（付けた名前を含む）、リマインダーの設定と時刻、オンボーディングやレビュー依頼の記録、Pro の利用状態を最後に確認した結果、ダウンロードした音声データは、本サービスの提供のために端末内に保存します。本サービスには、アカウント登録の機能や、これらの情報をクラウドに同期する機能はありません。端末のバックアップ・復元による保存の扱いは、OS や利用者の設定に従います。

2. 外部サービスで取り扱う情報と目的
本サービスでは、次の外部サービスを利用します。氏名やメールアドレスなどを当社が独自に送信していない場合でも、各サービスの識別子によって、同じ端末やインストールでの利用を区別できることがあります。

・Firebase Analytics（Google）：画面の表示、睡眠セッションの開始・終了、タイマー・声・環境音などの機能の利用状況、課金画面の表示や購入の結果、端末・OS・アプリの情報、アプリインスタンス ID などの識別子（OS の設定や許可の範囲で広告 ID を含む）を、利用状況の分析と本サービスの改善のために利用します。お気に入りの名前やリマインダーの時刻は送信しません。同意が必要とされる地域では、同意の内容に従って収集します。
・Firebase Crashlytics（Google）：クラッシュやエラーの情報（スタックトレース、発生時のアプリの状態）、端末・OS・アプリの情報、利用セッションの情報、インストール識別子などを、不具合の調査と改善のために利用します。
・Google AdMob：広告の表示（「3. 広告の表示」を参照）のために、IP アドレスから推定される大まかな位置、端末の識別子（広告 ID を含む）、広告の表示・操作、診断・性能に関する情報などを、広告の配信、効果の測定、不正の防止のために取り扱います。広告の配信と効果の測定には、Google とその提携先が関わる場合があります。
・Google User Messaging Platform（UMP）：同意が必要かどうかを判定し、必要な地域では広告と計測に関する同意や選択を確認して、その結果を端末に保存します。iOS では、トラッキングの許可を求める前の説明も UMP で表示します。判定や画面の表示のため、Google が端末・アプリの情報や IP アドレスなどを処理します。
・RevenueCat：SDK が発行する匿名の利用者 ID（App User ID）、購入履歴、レシート・購入トークン、商品・購読の状態、ストアの国・通貨、端末・アプリの技術的な情報などを、Pro の利用権の確認・復元、不正の防止、購入状況の分析のために取り扱います。購入・決済は Apple または Google のストアで行い、当社はクレジットカード番号やストアのパスワードを取得しません。
・GitHub Pages（GitHub）：声の音声データを配信します。音声データを取得する際、IP アドレスなどの接続情報が配信事業者によって処理されます。

各サービスの取り扱いについては、次の公式ポリシーもご確認ください。
Google プライバシーポリシー：https://policies.google.com/privacy
Google のサービスを使用するサイトやアプリから収集した情報の Google による使用：https://policies.google.com/technologies/partner-sites
Firebase のプライバシーとセキュリティ：https://firebase.google.com/support/privacy
RevenueCat プライバシーポリシー：https://www.revenuecat.com/privacy
GitHub のプライバシーに関する声明：https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement
Apple プライバシーポリシー：https://www.apple.com/legal/privacy/

3. 広告の表示
無料プラン（無料体験やサブスクリプションの終了後を含む）では、ホーム、声と環境音を選ぶ画面、設定画面に、Google AdMob のネイティブ広告を表示します。睡眠セッションの再生中・一時停止中は広告を表示しません。Pro（無料体験中・購読中）では広告を表示しません。
広告 SDK の初期化と広告の読み込みは、必要な同意を確認した後に行います。同意の確認と広告 SDK の初期化は、プランに関係なく行われる場合があります。
表示する広告の内容区分の上限は、全年齢向け（G）に設定しています。
広告がパーソナライズされるかどうかは、同意の内容、OS の設定、地域の規制によって異なります。

4. 広告 ID と同意の管理
・欧州経済領域（EEA）・英国・スイス、米国の一部の州など、同意や選択の機会が必要とされる地域では、UMP の画面で、広告と計測に関する同意や選択を確認します。
・iOS では、トラッキングの許可を求める前に説明を表示します。トラッキングを許可した場合に限り、広告識別子（IDFA）が広告の配信と効果の測定に利用されます。許可は、iOS の「設定」>「プライバシーとセキュリティ」>「トラッキング」からいつでも変更できます。
・Android では、広告 ID を広告の配信と効果の測定に利用します。Firebase Analytics も広告 ID を収集します。広告 ID は、端末の設定からリセットまたは削除できます（設定の場所は、機種や OS のバージョンによって異なります）。
・同意や選択は、本サービスの「設定」>「サポート」>「広告のプライバシー設定」からいつでも変更できます。この項目は、変更の機会が必要とされる地域でのみ表示されます。

5. 通知
リマインダー（Pro）と、無料体験が終わる前のお知らせは、端末内で予約するローカル通知です。通知の時刻を当社や外部サービスに送信しません。通知は、OS の設定で許可した場合に表示されます。

6. 利用目的
当社は、取得した情報を、本サービスの提供・維持・改善、利用状況の分析、不具合の調査、Pro の利用権の確認・復元、広告の配信と効果の測定、不正の防止、お問い合わせへの対応、法令や規約に違反する行為への対応、本サービスや本ポリシーの変更のお知らせのために利用します。

7. 委託・第三者提供と日本国外での処理
当社は、上記の目的のために、外部サービスの提供者に情報の処理を委託し、または情報を送信します。情報は、提供者の設備などにより、日本国外（米国など）で処理される場合があります。提供者の取り扱いは、上記の公式ポリシーに従います。当社が別に保有する個人情報を第三者に提供する場合は、委託や事業の承継に伴う場合、法令に基づく場合などを除き、必要な同意その他の適法な手続きに従います。

8. 保存期間と削除
外部サービスの情報は、その目的、提供者の方針、当社の設定に従って保存・削除されます。Firebase Crashlytics では、クラッシュの情報と関連する識別子について、90 日後に本番・バックアップのシステムからの削除処理が始まります。購入の権利や取引の記録は、権利の確認や法令上の義務に必要な期間、保存される場合があります。
端末内の情報は、アプリの削除やアプリのデータの消去によって削除できます。ただし、OS のバックアップ、ストアの取引記録、外部サービスに送信済みの情報が同時に削除されるとは限りません。

9. 安全管理
当社は、情報への不正アクセス、漏えい、紛失などを防ぐため、アクセスの管理や通信時の保護など、取り扱いに応じた安全管理措置を講じます。講じた措置の詳細は、末尾の連絡先にご連絡いただければ、法令に従って個別に回答します。

10. 利用者の請求とお問い合わせ
当社が保有する個人情報の開示、訂正、利用停止、削除などをご希望の場合は、末尾の連絡先にご連絡ください。必要な範囲で本人確認を行い、法令に従って対応します。識別子を特定できない場合など、対応できる範囲に限りがあるときは、その理由をご案内します。ストアが保有する取引の情報などは、各提供者での手続きが必要な場合があります。

11. 本ポリシーの変更
本ポリシーを変更する場合は、このページに変更後の内容と施行日を掲載し、重要な変更は本サービス内など適切な方法でお知らせします。
