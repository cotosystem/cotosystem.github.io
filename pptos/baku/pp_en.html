Privacy Policy

Coto System Co., Ltd. ("we", "our", or "us") sets out this Privacy Policy for the app "BAKU — Smartphone Health Record" (the "App").

1. Basic Policy
All diagnostics in the App (installed-app inventory, permission changes, and data-usage analysis) run on-device. Diagnostic data is not automatically sent off-device.
The App does not include ad SDKs, third-party analytics SDKs, or crash-reporting SDKs.

2. Information Processed On Device
The App processes and stores the following information on the user's device:
- Installed app inventory (app name, package name, install time, source store)
- Declared permissions and grant status per app
- Per-app data usage (only when Usage Access is granted)
- Diagnostic results (scores, change events, history)

3. Purposes of Use
We use this information to provide app inventory, detect app add/remove and permission changes, monitor data-usage changes, and display diagnostic results and notifications.

4. Cases Where Off-Device Transmission Occurs
Only when the user explicitly submits feedback from Settings > Feedback, the following information is sent off-device:
- Feedback category and message content
- Reply email address (only if entered)
- Attached image or video (only if attached, one file up to 4 MB)
- App version, OS type/version, language setting
- Random install ID and request ID

Recipients are our feedback intake infrastructure (fb2dc on Google Cloud) and linked Discord channels. These are used for support response and quality improvement.

5. Information Not Collected for Diagnostics
For diagnostics, the App does not collect message/photo/file contents, communication payloads, destination domains or IP addresses, or advertising/tracking identifiers.

6. Retention and Deletion
- Detailed snapshots (such as permission snapshots) are automatically deleted after the selected retention period (30/90/180 days).
- Daily data-usage records are automatically deleted after one year.
- Score trends and change history remain on-device.
- Uninstalling the App removes on-device records.
- Submitted feedback data may be retained on the intake infrastructure or Discord for the period necessary for support and quality improvement.

7. User Consent and Controls
- Installed-app inventory access starts only after explicit user consent.
- Usage Access (for data-usage collection) and notification permission are optional.
- Feedback is transmitted only by the user's explicit submission action.

8. Security Management
We implement security measures in line with applicable laws and the App's actual implementation.
